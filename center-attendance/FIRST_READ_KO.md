# 통합본 적용 안내 — 2026-11-09

이 파일은 11월 6일 수정본을 적용하지 않은 상태에서 사용할 수 있는 전체 소스입니다. 이전 압축파일을 먼저 적용하지 마세요.

## 포함된 내용

- 정기수업의 적용일 변경, 과거 기록 보존, 종료·회차 취소 처리
- 보강 40분 기준의 완료/예약/잔여 관리와 CSV 수정
- 아이·선생님·바우처별 모든 요일 합산 월 4회, 보강 제외
- 사유를 남기는 3회 예외, 다음 달 회차의 전월분 배정, 휴무 취소, 월 마감·해제

## 적용 순서

1. 현재 앱과 Supabase를 백업합니다.
2. `migrations/000_preflight_readonly.sql`로 기존 데이터와 권한 상태를 확인합니다. 조회 전용입니다.
3. 운영과 분리된 테스트 DB에 `migrations/APPLY_ALL.sql`을 실행합니다. 001~007 전체 변경이 포함되어 있습니다. 개별 SQL을 추가로 실행할 필요가 없습니다.
4. 이 폴더를 새 프로젝트 폴더에 풀고, 테스트 Supabase 환경값을 설정합니다. 실제 키와 `.env.local`은 압축파일에 포함하지 않았습니다.
5. `npm.cmd ci`, `npm.cmd test`, `npm.cmd run typecheck`, `npm.cmd run build`, `npm.cmd run dev` 순서로 확인합니다.
6. 관리자 화면의 **월별 수업·이월**에서 월 4회 합산, 3회 예외, 이월 배정을 확인합니다. 세부 검증 목록은 `UPDATE_GUIDE_KO.md`에 있습니다.
7. 실제 데이터 검증과 기존 권한 문제 정비 후 앱과 SQL을 함께 운영에 반영합니다.

## 주의할 구분

- 11월 3회 + 12월 5회에서 12월 한 회차를 전월분 배정하면 11월 4회, 12월 4회입니다. 실제 수업 날짜는 바뀌지 않습니다.
- 결석은 배정된 정규 회차에 포함됩니다. 출석과 결석은 별도 표시하고, 결석의 보강은 월 4회에 더하지 않습니다.
- 월별 화면 CSV는 횟수 반영 월 기준입니다. 기존 CSV는 실제 수업 월 기준이며 선생님 CSV에는 횟수 반영 월을 추가했습니다.
- 기존의 연결이 불분명한 보강/정기 일정은 자동으로 추정해서 정정하지 않습니다.
- 선생님·바우처가 달라진 항목의 월 목표를 자동 합치거나 두 달 이상 건너뛰어 이월하지 않습니다.

이 작업은 업데이트 파일 작성과 합성 데이터 테스트까지 수행했습니다. D: 원본 수정, 운영 DB 실행, 실제 로그인 브라우저 검증은 수행하지 않았습니다. 기존 전체 API 인증/RLS와 lint 문제도 남아 있으므로 운영 검증 완료본이라고 보시면 안 됩니다.
